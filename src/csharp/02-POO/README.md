# Programação Orientada a Objetos

> Os quatro pilares da POO em C# — encapsulamento, herança, polimorfismo e abstração.

---

## O que esse módulo cobre

| Pasta | Conceito |
|-------|----------|
| `Exemplos/Heranca` | Classe base + classe derivada, `virtual`/`override` |
| `Exemplos/Interfaces` | Contratos com `interface` e implementação concreta |

---

## Takeaways

- **Herança** reaproveita comportamento de uma classe base
- **Interfaces** definem contratos sem implementação
- `virtual`/`override` habilitam polimorfismo em tempo de execução

---

## Rodar

```bash
cd Exemplos/Heranca && dotnet run
```
